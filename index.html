I am a Senior Research Fellow at Lero, the Research Ireland Centre for Software at the University of Limerick, working with Prof. Lionel C. Briand. Before joining Lero I received my Ph.D. in Computer Science from Peking University, supervised principally by Prof. Yingfei Xiong and Prof. Lu Zhang, and also advised by Prof. Dan Hao and Prof. Xin Zhang.

My research is on software testing and debugging in the era of large language models. LLMs are quickly becoming the authors of production code, and that moves the bottleneck: the hard part is no longer writing software, but knowing whether to trust it. I build the correctness infrastructure for that world — combining large language models with program analysis and automated reasoning so that generated tests, oracles and repairs rest on evidence rather than plausibility, and so that we measure what coding agents can really do rather than what benchmarks flatter them into appearing to do.

02Research

Software fails in ways that are hard to reproduce, hard to localise and hard to test for. My work builds automated techniques that attack that problem from two directions: statistical and probabilistic reasoning over program structure, and large language models grounded by program analysis so their output can be trusted. Five threads run through it.

01

LLM-Based Test Generation

Making generated tests actually useful — guided by mutation scores, aware of call chains across a project, free of brittle mocks, and equipped with oracles that multiple agents agree on rather than hallucinate.

TSE 2026TOSEM 2026MUTGENCAT

02

Automated Debugging & Program Reduction

Delta debugging reframed probabilistically: model the likelihood that each element is relevant, and spend test executions where they pay off. ProbDD and its abstract-syntax-tree successor reduce failure-inducing inputs substantially faster than the classical algorithm.

FSE 2021ISSRE 2023Distinguished Paper

03

Compiler Testing & Validation

Compilers are tested by generating programs, which is cheap, and by running them, which is not. Predicting coverage before execution and diversifying configurations using testing history both push far more bugs out of the same budget.

ASE 2019TSE 2021Distinguished Paper

04

Program Analysis & Repair

Fixing compilation errors as a shortest-path CFL-reachability problem with attribute checking, and Bayesian formulations that let a static analysis reason about uncertainty instead of pretending it does not exist.

ASE 2023OrdinalFixBayesian Analysis

05

Evaluating LLM Agents Honestly

Test-based benchmarks flatter coding agents: weak test suites accept wrong patches. Strengthening benchmarks adversarially reveals how much reported success is real, and characterising failure modes on genuine GitHub issues shows where agents still break.

ICML 2026SWE-ABSBenchmarking
